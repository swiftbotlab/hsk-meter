    What is counted

    Anyone can register endpoints on the settlement contract, so contract-wide totals are not this service's numbers. Only endpoints 1 and 2 are counted. The contract fixes an endpoint's provider and payee when it is registered, so the page pins both registrations: provider 0x30CC…1160, payee 0xA8A4…a48D. Withdrawals and credit belong to the payee, so they cover every endpoint that pays it.
